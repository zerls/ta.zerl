引、为什么要学 ReSTIR？

如果说 1990 年代是 PT，2000 年代是 BDPT/MLT，2010 年代是 Path Guiding，那么 2020 年代毫无疑问是 ReSTIR 的时代。

ReSTIR 是过去五年间实时光线追踪领域最重要的算法突破之一，它的关键贡献并不是发明了一个全新的采样方法，而是把一个 2005 年就被提出但长期没有被实时社区注意到的算法 —— RIS (Resampled Importance Sampling) [Talbot 2005] —— 与 GPU 友好的水库采样 (Weighted Reservoir Sampling) 结合，并加入时空复用机制，使其在 1 spp 下也能产出近似离线渲染品质的结果。

它已经被部署在多款 AAA 产品中：

  • Cyberpunk 2077 (RT Overdrive Mode + Phantom Liberty)
  • Portal with RTX
  • Sword and Fairy 7 (国产首款全 RT 大作)
  • NVIDIA RTXDI / RTXGI SDK

学完这篇笔记后，你应当能够：

  1. 推导 RIS / GRIS 的无偏性
  2. 理解 Shift Mapping 与 Jacobian 行列式的几何含义
  3. 在 Falcor / Unity URP / 自研引擎里实现一个最小可用的 ReSTIR DI/GI
  4. 知道哪些”看起来理所应当的优化”实际上会引入难以调试的偏差

一、核心动机：为什么样本可以复用？

1.1 实时路径追踪的根本困境

实时渲染的硬约束是 每帧 16 ms (60 FPS) 或 33 ms (30 FPS)，每像素往往只能投出 1 条路径甚至更少。回顾蒙特卡洛积分器：

它的方差由 与 的匹配度决定。当 时方差为零；二者偏离越大，噪声越严重。

核心矛盾：要让 接近 需要”知道哪些路径携带能量”，但这本质上与渲染问题等价——是个鸡生蛋的悖论。

传统应对：

  • 加样本数 4× 样本只换 2× 噪声下降，性价比奇差
  • 更好的 PDF（光源采样、BSDF 采样、MIS） 仍然在单个像素内独立工作
  • 后置降噪（SVGF/OIDN） 在颜色空间盲目滤波，丢失能量、产生 ghosting

1.2 ReSTIR 的关键洞察

相邻像素看到的光照虽然不完全相同，但”好路径”往往也是邻居的好路径。

这意味着：如果像素 A 通过昂贵的随机投射”偶然”找到了一条携带能量的路径，那么相邻像素 B、C、D 没必要重新昂贵地试错——直接借用并稍作修正即可。

ReSTIR 的本质，可以理解为 “对采样分布而非颜色进行滤波”：

维度 后置降噪 (SVGF) ReSTIR
滤波对象 已积分的颜色 采样分布本身
信息保留 只剩 G-Buffer + 颜色 完整 PDF / 路径信息
偏差性质 通常有能量损失 数学上可证明无偏
复用单位 像素颜色 单个采样路径

ReSTIR 的伟大之处在于：在丢弃任何信息之前进行重采样，因此可以在数学上严格保证无偏。

四、ReSTIR GI：扩展到间接光照

4.1 从 DI 到 GI 的根本难点

直接光的 在光源表面，可以无差别在邻居间共享。但间接光的次级反弹点 是任意场景表面，它的 spatial reuse 会立刻撞上一系列问题：

难点 例子
邻居 不同，连接 的几何项变化巨大 一个像素的法线背对 ，BSDF 直接是 0
Glossy / Specular BSDF 对方向极敏感 镜面像素重用漫反射像素的 会产生几乎零贡献
邻居像素间可能被几何遮挡 “穿墙”漏光
域之间存在概率密度变换 必须乘 Jacobian 否则有偏差

ReSTIR GI [Ouyang 2021] 的策略：仍然像 DI 一样把 当作待复用的 sample，使用 identity shift in area measure——即简单地把次级顶点从一个像素搬到另一个，重新连接 。论文中通过缓存 作为 outgoing radiance 复用。

⚠️ ReSTIR GI 是有偏的实用近似。它假设 处的出射 radiance 在不同入射方向下相同（实际上只对 Lambertian 严格成立）。对粗糙度低的材质会出现可见错误。

4.2 Shift Mapping：跨域复用的数学武器

Shift Mapping 是 ReSTIR GI 与 ReSTIR PT 之间最大的概念分水岭。

定义：在路径空间 与路径空间 之间的双射 。

需要满足：

  • 确定性（同一输入永远映射到同一输出）
  • 单射（不同源路径不能映射到同一目标路径）
  • 可逆（必须存在 ）
  • 可能”未定义”（某些路径无法 shift）

4.3 Jacobian 行列式：概率密度的修正项

当 时，PDF 需要按 Jacobian 修正：

对应的 UCW 变换：

Reconnection Shift 的 Jacobian（solid angle measure 下）：
$$
\left|\frac{\partial \omega^y_{k-1}}{\partial \omega^x_{k-1}}\right|
= \left|\frac{\cos\theta^y_k}{\cos\theta^x_k}\right| \cdot \frac{|\mathbf{x}k - \mathbf{x}{k-1}|^2}{|\mathbf{x}k - \mathbf{y}{k-1}|^2}
$$

直觉：距离越近，立体角越大；夹角越小，投影面积越大。

三种 Shift Mapping 对比示意（蓝=源像素 base path，绿=目标像素 offset path）

Shift 类型 工作方式 适用 不适用 Jacobian
Reconnection 固定 ，重连 → 漫反射 / 粗糙 镜面 / 低粗糙 glossy 简单（几何项比）

4.5 Hybrid Shift 的两个判定条件

ReSTIR PT 的 hybrid shift 用两个条件决定哪个顶点 作为 reconnection 点：

距离条件（避免极短重连段，几何项爆炸）：
$$
\min(|\mathbf{x}k - \mathbf{x}{k-1}|, |\mathbf{x}k - \mathbf{y}{k-1}|) \ge d_{\min}
$$

粗糙度条件（避免低粗糙顶点上的连接）：
$$
\min\bigl(\alpha_{\mathbf{x}{k-1}}(\ell{k-1}), \alpha_{\mathbf{y}{k-1}}(\ell’{k-1}), \alpha_{\mathbf{x}k}(\ell_k)\bigr) \ge \alpha{\min}
$$

可逆性约束：不存在更早的 同时满足以上条件——否则 offset path 会做出不同选择，破坏双射。

5.1.2 三种 MIS 权重的对比

方案 复杂度 偏差 何时用
1/M weights 有偏（除非所有候选独立同分布） 仅在 initial sampling 内部
Contribution MIS 无偏（仅对选中样本算 MIS） 通用、性能优先
Generalized Balance 无偏 候选少（≤ 5）时
Pairwise MIS (defensive) 无偏 Spatial reuse 推荐默认

Pairwise MIS（defensive 形式）：将每个邻居与”canonical sample”（当前像素自身）配对计算 balance heuristic，复杂度 但收敛性接近 的 balance heuristic：

$$
\begin{aligned}
m_i(x) &= \frac{1}{M} \cdot \frac{\hat{p}_i(x)}{\hat{p}_i(x) + \hat{p}c(x)/(M-1)}, \quad i \neq c\
m_c(x) &= \frac{1}{M}\left(1 + \sum{j\neq c} \frac{\hat{p}_c(x)/(M-1)}{\hat{p}_j(x) + \hat{p}_c(x)/(M-1)}\right)
\end{aligned}
$$

5.2.3 Hybrid Shift 的内核切分

问题：把 random replay + reconnection + visibility test 塞在一个大 kernel 里：

  • 寄存器使用爆炸 → occupancy 暴跌
  • 不同像素分支严重不一致 → execution divergence

优化（NVIDIA 实测有效）：

  1. 小 kernel 分离：random replay kernel → 写中间结果到 global memory → reconnection kernel
  2. Stream compaction：只把”需要 replay”的像素打包成稠密线程，避免 idle warps

在 Veach Ajar 场景上，第 ① 步带来 ~40% shader time 减少，第 ② 步在第 ① 步基础上再减 ~40%。

5.3 Visibility Reuse：偏差陷阱重灾区

ReSTIR DI 原始论文为了省 shadow ray 提出”重用 visibility”——历史 reservoir 已经测过 visibility 就不再测。但这会引入难以察觉的偏差（场景动态变化时尤甚）。

建议：

  1. 默认在 target function 里始终包含
  2. 只有在能容忍 ghosting/light leaking 的场景下才关闭 visibility 重测
  3. 用 disocclusion mask 强制关键区域重测

5.4 Boiling 与 Correlation：相关性的代价

症状：高时间复用下，相邻像素长期共享同一个样本，画面上出现块状的、随时间”沸腾”的低频噪声。

对策：

  • Confidence cap：见 3.5
  • Boiling filter：Bitterli 2020 提出的简单滤波，把 远超邻居均值的 reservoir 重置（注意：会引入轻微偏差）
  • Permutation sampling：在 spatial reuse 时打散邻居选择模式
  • 降低空间复用半径或轮数

6.2 ReSTIR PT：完整路径追踪

ReSTIR GI 假定单次反弹缓存出射 radiance，是有偏近似。ReSTIR PT [Lin 2022] 通过 Hybrid Shift + GRIS 框架，将路径复用扩展到任意长度路径，并保持无偏。

关键概念：

  • Lobe-tagged path：路径里每个顶点带一个 lobe 索引 ，保证 random replay 的双射
  • Primary Sample Space：用 的 RNG 序列参数化路径，random replay 部分 Jacobian 为 1

6.3 Volumetric ReSTIR：参与介质

体积渲染中：

  • 路径顶点可以在 3D 体积内，不再是 2D 流形
  • Transmittance 通常无闭式解
  • 距离采样需要 delta tracking，但 PDF 未知

Volumetric ReSTIR 用低分辨率分段常数体积近似 ，在 shading 时再用高精度 transmittance 评估。两种 shift：

  • Vertex reuse：复制 序列（快但易出 firefly）
  • Direction reuse：复制 方向序列（慢但鲁棒）

6.4 Cyberpunk 2077 集成经验

Pawel Kozlowski (NVIDIA DevTech) 与 Giovanni De Francesco (CDPR) 在 SIGGRAPH 2023 给出的 takeaway：

  • 艺术家友好性：ReSTIR 让灯光师不再需要手动放置 area light approximation——可以用真实 mesh emissive。
  • 关卡复杂度：Phantom Liberty 中 Dogtown 区域有数十万 dynamic emissive triangle，传统方案不可能实时
  • 依然需要 denoiser：ReSTIR 大幅减少 spp 需求，但 1 spp 仍有噪声，搭配 ReBLUR / NRD
  • Disocclusion 处理：相机快速移动时是最大挑战，需要小心的历史失效策略

七、上手路线图

这是 SIGGRAPH 2023 课程中所有作者一致强调的：不要试图一步到位，否则你会陷入数月的调试地狱。

💀 痛苦经验：不要在阶段 1 就开始优化。修复一个被优化埋藏的偏差，比保持基线版本正确并逐步优化，工作量是指数级别差异。
