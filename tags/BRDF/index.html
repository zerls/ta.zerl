「PBR 系列」第一篇 · 理论基石：从渲染方程到 Cook-Torrance 框架
PBR 不是某一个公式，而是一个由「渲染方程 + 微表面理论 + 能量守恒 + 互易性」构成的框架。Cook-Torrance 把镜面 BRDF 拆成 D / G / F 三项，于是后续四十年的工作都可以归类到对这三项的精修——以及对 Lambert 漫反射的扩展。
